# 🖼️ Motivational Poster Website

A minimal web project that displays a **motivational-style poster** generated from a random meme retrieved through the **Meme API**. The page updates the image and title dynamically, creating a simple and playful poster layout.

---

## ✨ Features

- **Automatic meme fetching** using a public API  
- **Dynamic DOM updates** for image and title  
- **Clean, centered layout** styled as a poster  
- **Google Fonts integration** for elegant typography  

---

## 📁 Project Structure

- **index.html** — Base structure and font imports  
- **style.css** — Poster layout and visual styling  
- **script.js** — Async function that retrieves and displays the meme  
- **/images** — Contains the initial fallback image  

---

## 🎯 Purpose

This project is ideal for practicing:

- **DOM manipulation**  
- **Fetch API**  
- **Working with public APIs**  
- Basic HTML and CSS structure
